# Day 16 — Build Your First Stock Research Skill

## Objective

Created a reusable Claude Custom Skill to analyze listed companies using fundamental analysis instead of repeating prompts manually.

---

## Skill Built

**Skill Name:** `stock-fundamental-research`

### Description

Analyze Indian and global listed companies using fundamentals, financial statements, business quality, competitive advantages, valuation, risks, and growth prospects. Generate evidence-based research reports and investor-friendly summaries. Never provide direct buy, sell, or hold recommendations.

---

## What I Did

* Opened Claude and explored the Skills section
* Created a new Custom Skill
* Added provided description and instructions
* Saved the reusable workflow
* Tested the skill on selected stocks
* Generated:

  * Fundamental analysis report
  * Valuation insights
  * Ownership trends
  * Risk observations
  * Price chart review
  * Stock comparison

## Key Learnings

1. Custom Skills reduce repetitive prompting.
2. Structured prompts produce more consistent outputs.
3. Financial research becomes easier with reusable workflows.
4. Evidence-based analysis improves clarity.
5. AI can summarize complex financial data faster while still requiring human verification.
